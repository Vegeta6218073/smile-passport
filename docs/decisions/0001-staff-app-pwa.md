# 0001: Staff app is a mobile-first PWA

Status: proposed. Confirm at the end of Phase 0, week 1, after the spike below.

## Decision
One mobile-first Progressive Web App for all staff roles, with a wider desktop layout for front-desk computers.

## Why
- Staff move between phones and shared clinic computers.
- One codebase suits a small team.
- No app-store review, so fixes reach every clinic the same day.
- Installable to the home screen, and can receive notifications.

## Spike (record results here)
- [ ] Install to home screen on the pilot staff's actual phones
- [ ] Push notification received on those phones (needed in Phase 3)
- [ ] Camera upload works (needed for documents and scans)
- [ ] Sign-in with 2FA works from the installed app

## Revisit native apps if
Offline-first use, heavy camera or background features, or device-level needs prove necessary.
